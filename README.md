# ระบบรับสมัคร สกร.ระดับอำเภอเสนา

เปิด `index.php` ผ่าน PHP 8.1+ ที่มี mysqli, fileinfo และ zip พร้อม MySQL ตาม config.php

สำหรับทดสอบผ่าน PHP server ให้ใช้ router เพื่อปิดการเข้าถึงเอกสารโดยตรง:

```sh
/Applications/MAMP/bin/php/php8.3.14/bin/php -S 127.0.0.1:8765 -t . router.php
```

## ติดตั้งจาก GitHub

1. Clone repository และรัน `composer install`
2. คัดลอก `config.example.php` เป็น `config.local.php` แล้วใส่ค่าฐานข้อมูลและ SMTP ของเครื่อง
3. เปิด MySQL และ PHP 8.1+ พร้อม mysqli, fileinfo และ zip
4. เปิดเว็บผ่าน Apache ของ MAMP หรือคำสั่ง preview ข้างต้น ระบบสร้างตารางให้อัตโนมัติ
5. ระบบใหม่ใช้รหัสเจ้าหน้าที่เริ่มต้น `1234` ให้เปลี่ยนที่เมนูตั้งค่าก่อนเปิดใช้งานจริง

Git ไม่เก็บ config.local.php, vendor, ข้อมูลผู้สมัคร, ไฟล์แนบส่วนตัว หรือ ZIP สำรอง เมื่อติดตั้งเครื่องใหม่ต้องย้ายฐานข้อมูล/สำรองผ่านช่องทางส่วนตัวแยกจากโค้ด

## ภาคเรียน
- เปิดรับสมัครเริ่มต้น 2/2569 เปลี่ยนได้ที่ เจ้าหน้าที่ → จัดการภาคเรียน
- ตัวกรอง สถิติ และ CSV แยกตามภาคเรียน เลขบัตรเดียวกันสมัครได้คนละภาคเรียน
- ข้อมูลเดิมระบุ `legacy` เพื่อไม่เดาภาคเรียน สามารถสำรองแล้วย้ายข้อมูลเดิมทั้งหมดเข้าภาคเรียนที่ตรวจสอบแล้วได้ หากข้อมูลเดิมมีหลายภาคเรียน ต้องตรวจแยกรายการก่อน
- ระบบเพิ่มคอลัมน์และปรับดัชนีฐานข้อมูลเดิมอัตโนมัติเมื่อเชื่อมต่อ

## จัดการผู้สมัครและเอกสาร
- แก้ไขข้อมูลทุกส่วนและภาคเรียนรายคนจากหน้า “แก้ไขข้อมูล / ภาคเรียน” ระบบสำรองก่อนแก้ไข
- เปลี่ยนไฟล์แนบทีละเอกสารได้ ตรวจชนิดไฟล์จริงและขนาดไม่เกิน 5 MB
- ตัวแสดงภาพรองรับย่อ/ขยาย หมุน และปรับพอดีจอ พร้อม PDF หลายหน้าและดาวน์โหลด
- ตัวอ่าน PDF.js 4.10.38 เก็บในโปรเจ็กต์ (Apache 2.0) โหลด PDF ผ่าน endpoint ของระบบ ไม่ส่งเอกสารไปบริการภายนอก อ้างอิง https://mozilla.github.io/pdf.js/examples/
- เอกสารผู้สมัครเข้าผ่าน admin/document.php ซึ่งตรวจสิทธิ์เจ้าหน้าที่ โฟลเดอร์เอกสารมี .htaccess ปิดการเข้าถึงโดยตรงบน Apache (ต้องเปิด AllowOverride)
- เปิดหรือปิดรับสมัครชั่วคราวได้ที่หน้าจัดการภาคเรียน

## สำรอง ล้างข้อมูล และกู้คืน
- ลบรายคนหรือล้างภาคเรียนจะสร้าง ZIP และตรวจ SHA-256 ของข้อมูลและทุกไฟล์แนบก่อนลบ หากไฟล์หายหรือสำรองล้มเหลว จะไม่ลบทะเบียน
- ZIP มี registrations.json (ทุกช่องข้อมูล), registrations.csv สำหรับ Excel, checksums.json และ uploads/ (ไฟล์แนบ)
- สำรองอยู่ใน `../sena-private-backups` เมื่ออ้างอิงจากโฟลเดอร์ htdocs (อยู่นอก web root) ดาวน์โหลดผ่านหน้าเจ้าหน้าที่ที่ตรวจสิทธิ์เท่านั้น
- เลือกเก็บเอกสารต้นฉบับ หรือให้ลบไฟล์ที่ไม่มีผู้สมัครอื่นใช้งานหลังสำรองสำเร็จได้
- กู้คืนได้ที่ จัดการภาคเรียน → ไฟล์สำรอง → ตรวจสอบและกู้คืนไฟล์นี้ → พิมพ์ “กู้คืน”
- กู้คืนเฉพาะเลขบัตร/ภาคเรียนที่ยังไม่มีในระบบ ข้ามข้อมูลเดิม ไม่เขียนทับ กำหนดหมายเลขรายการใหม่ ตรวจไฟล์ชื่อซ้ำและ rollback หากผิดพลาด
- เปลี่ยนฐานข้อมูลหรือที่เก็บสำรองในสภาพแวดล้อมทดสอบผ่าน SENA_DB_NAME / SENA_BACKUP_DIR ได้ ค่าเริ่มต้นของระบบจริงคงเดิม

## ตรวจสอบ
ใช้ PHP ของ MAMP:

```sh
/Applications/MAMP/bin/php/php8.3.14/bin/php tests/integration.php
```

ชุดทดสอบสร้างฐานข้อมูลและไฟล์ชั่วคราวแล้วล้างออก: ย้าย schema เดิม, ความซ้ำภายใน/ข้ามภาคเรียน, สำรองอย่างเดียว, แก้ไขพร้อมสำรอง, ย้ายชนภาคเรียน, ล้างเฉพาะภาคเรียน, ลบไฟล์ที่สำรองแล้ว, กู้คืนทะเบียน/เอกสาร, กู้คืนซ้ำ, ปฏิเสธ ZIP เสีย และป้องกัน path traversal

ตรวจ HTTP การสมัครครบสามเอกสาร การสมัครซ้ำ วันเกิดผิด CSRF และสิทธิ์เอกสาร พร้อมตรวจ UI มือถือ 390px และการซูม/หมุนภาพด้วยข้อมูลจำลองแยกจากฐานข้อมูลจริง
